# Player surface

Mode: Operate. A learner imports a local JSON stack, reads one rich prompt, reveals its answer, self-grades, and continues. No account, network stack fetch, or hidden progress claim. Public demo demonstrates the player before any import.

## Direction contract

**THESIS:** A reprographic light table for inspecting one thought at a time, not a grid of cards. The answer is a deliberate second layer, never an automatic flip animation that obscures the content.

**OWN-WORLD:** Cool backlit pale-cyan field, deep blue-green ink, precise teal controls, and a restrained amber mark for revisits. Thin registration rules, crisp numerals, and translucent apparatus surround—but never cover—the legible HTML face.

**STORY:** The learner sees the current question and its queue context, recalls, reveals, chooses Correct or Review again, and sees the queue change. Importing a private file never requests GitHub credentials.

**FIRST VIEWPORT:** A narrow masthead puts stack identity left and file import right; below it, a broad face canvas takes most of the width and height. A compact session rail shows pending items without a card grid. The centered Reveal answer control sits directly beneath the face and is replaced by two grade controls. At phone widths the rail becomes one status line above the canvas.

**FORM:** Reprographic light table, grounded direction six of seven; concept seed 8e6cc712. Signature interaction: revealing swaps an isolated face frame as a translucent answer layer settles, while the grade changes the pending count without moving the reading surface. Motion respects reduced-motion.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Unresolved: no deployment bucket or distribution provided. The S3/CloudFront upload is a separate operator action.
